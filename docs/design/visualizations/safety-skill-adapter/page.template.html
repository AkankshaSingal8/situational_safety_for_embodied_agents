Read the diagram with these boundaries

  • Learned offline: only the shared adapter receives weight updates.
  • Fixed at runtime: pretrained policy, text encoder and trained adapter.
  • Oracle grounding first: semantic facts and geometry are supplied in the main PoC.
  • Separate evaluation: intended obligations survive skill deletion or incorrect retrieval.
  • No safety guarantee: raw and shielded results must be measured separately.

The separate September 19 proof-of-life plan tests historical fact memory with fixed rules. This figure shows the v2 learned-adapter target, not that smaller experiment.

Inference. The skill and current scene condition a residual at every flow step. L0 executes the adapted prefix without semantic repair; L1 inserts the fixed checker. Actual behavior is scored independently in both cases.
